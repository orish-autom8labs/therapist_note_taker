- **Speakers:** Blue labels when speaker changes
- **Final Tokens:** Dark text (#2C3E50)
- **Non-Final Tokens:** Gray italic (#7F8C8D) with "(updating...)"
- **Auto-Scroll:** Scrolls to bottom as transcript grows

## 🔧 Technical Details

### Soniox SDK Configuration
```javascript
{
  model: "stt-rt-v3",
  enableLanguageIdentification: false,
  language: "he",  // Hebrew
  enableSpeakerDiarization: true,
  enableEndpointDetection: true,
}
```

### Token Management Pattern
```javascript
// CRITICAL: Follow official example
setFinalTokens(prev => [...prev, ...newFinalTokens]);  // APPEND
setNonFinalTokens(newNonFinalTokens);                 // REPLACE
```

### Auto-Save Intervals
- **localStorage:** Every 5 seconds
- **Server (Drive):** Every 60 seconds (1 minute)
- **Final Save:** On session end

### Session Timer Thresholds
- **Warning:** 45 minutes (75% elapsed)
- **Critical:** 55 minutes (91.7% elapsed)
- **Max Time:** 60 minutes (100% - auto-stop)

## 🎓 Key Learnings

### What Worked
1. **Using official SDK** - Eliminated audio format issues
2. **Direct client connection** - Removed server proxy complexity
3. **Correct token pattern** - Prevented duplicate text
4. **Incremental implementation** - Built features one at a time
5. **Preserving working code** - Didn't break Drive/Email

### What Changed
1. **Architecture** - Client → Soniox (direct) instead of Server proxy
2. **Security** - Temporary API keys instead of main key exposure
3. **Token Management** - Replace non-final tokens, not append
4. **UI/UX** - Added visualizer and timer for better feedback
